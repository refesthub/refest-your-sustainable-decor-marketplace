# ReFest: Your Sustainable Decor Marketplace

ReFest Marketplace Prompt

Build a modern, mobile-first web application called ReFest.

ReFest is a community marketplace where people can Buy, Sell, Rent, Exchange, and Donate festival decorations, starting with Ganpati decorations in Pune and Mumbai.

The design should feel like a mix of OLX, Airbnb, and Facebook Marketplace with a clean green sustainability theme.

Core Mission

Reduce festival waste by giving decorations a second life.
